# Занятие 05 — Task и async-await

**Практика 1:** реализовать `CheckServiceAsync` на `Task.Delay`, не блокировать вызывающий код и оставить меню пригодным для дальнейшего ввода. **Практика 2:** три независимые проверки — последовательно и через `Task.WhenAll`, сравнить время.

## Задания
1. Проверить имя сервиса.
2. Проверить отрицательную длительность.
3. Использовать `await Task.Delay(delay, token)`, не `Thread.Sleep`.
4. Вернуть `CheckResult` с именем, статусом, длительностью и сообщением.
5. Реализовать последовательное ожидание через await.
6. Создать все задачи параллельного запуска до ожидания.
7. Дождаться их через `Task.WhenAll`.
8. Вызвать сервис из меню через await, без `.Wait()`/`.Result`.
9. Обработать отмену и ошибки без пустого catch.
10. Добавить команду/режим контроля выполнения и продемонстрировать, что ожидание Task.Delay не блокирует поток.

Запуск: `dotnet run --project AsyncMonitor` и `dotnet run --project AsyncMonitor.Tests`.
